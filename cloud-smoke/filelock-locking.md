# filelock locking smoke check (Cloud)

- Repository: `gmfjc624d2-dot/filelock`, base commit `e2e7d709890ac08ec9e35eece65ef51f62df5cf5` ("Release 4.2.0")
- Environment: Claude Code on the web, Anthropic cloud container (`CLAUDE_CODE_REMOTE=true`,
  `CLAUDE_CODE_REMOTE_ENVIRONMENT_TYPE=cloud_default`); Linux 6.18.44, CPython 3.13.16, running as root
- Scope: native `FileLock` (= `UnixFileLock`, `flock`) only. No library code was changed and nothing was installed.

## Source references

**Ownership**

- `src/filelock/_api.py:742-752` and `:802`: the lock context is per-thread (`ThreadLocalFileContext`) unless
  `thread_local=False`. `is_singleton=True` shares one instance per path.
- `src/filelock/_api.py:1041-1051`: `is_locked` only reports whether *this instance* (in this thread) holds a descriptor.
  It cannot see a lock held by another process.
- `src/filelock/_api.py:1180` and `:1260-1264`: acquire bumps a reentrancy counter. `release()` is a no-op for an
  instance that holds no descriptor or was inherited across `fork`. It only decrements while the counter is above 1,
  unless `force=True`. Acquiring through an inherited instance raises `RuntimeError` (`:1306-1309`).
- `src/filelock/_api.py:1365-1379`: if a *different* instance in the same thread already holds the path, an
  infinite-timeout acquire raises `RuntimeError("Deadlock ...")` instead of hanging.
- `src/filelock/_unix.py:48-60`: a single `flock(LOCK_EX | LOCK_NB)` attempt per poll. `EACCES`/`EAGAIN`/`EWOULDBLOCK`
  mean contention. `:97-123`: the lock file is opened without `O_TRUNC`; `:146-165`: the winner truncates it under
  the lock and drops a hold whose inode was unlinked (`st_nlink == 0`). `:182-189`: release unlocks, then closes.
  The lock file is left in place (`:62-69`).
- `src/filelock/_unix.py:125-143`, `:172-180`: when `flock` returns `ENOSYS`, the lock falls back to `SoftFileLock`
  with a warning. `fallback_to_soft=False` makes it raise instead.

**Timeout**

- `src/filelock/_api.py:1149-1162`: `None` falls back to the instance defaults. A negative or `inf` timeout waits
  forever.
- `src/filelock/_api.py:1395-1434` (poll loop) and `:1607-1625` (give up when `blocking=False`, when `cancel_check()`
  returns true, or when `0 <= timeout < elapsed`). `:1428-1429` shortens the last sleep so it ends at the deadline.
- `src/filelock/_api.py:1199-1229`: a shared (`thread_local=False`) instance's admission gate also honors the timeout.
- `src/filelock/_error.py:8`: `Timeout` subclasses `TimeoutError`.

**Advisory vs non-cooperating writers**

- `docs/concepts.rst:497-523` ("Native locks are advisory") and `docs/how-to.rst:52-54`: native locks only block
  other acquirers. They do nothing to a process that writes the resource, or removes the lock path, without locking.
- `src/filelock/_soft.py:34-48`: `SoftFileLock` is a cooperative existence marker. Its `lifetime` expiry
  (`_api.py:1593-1605`) can produce overlapping holders.

**Existing tests**

- `tests/test_filelock.py`: `test_nested_acquire` (`:235`), `test_timeout` (`:369`), `test_non_blocking` (`:388`),
  `test_force_release_keeps_hold_of_live_thread` (`:620`),
  `test_shared_instance_released_on_another_thread_frees_the_acquirer` (`:1007`),
  `test_finite_timeout_gives_timeout_not_deadlock` (`:1747`), `test_infinite_timeout_gives_deadlock_not_hang`
  (`:1757`).
- I found no test in which a process writes the protected data, or unlinks a held native lock file, without taking
  the lock. The advisory boundary is documented but not tested.

## Check

A child process holds the lock while the parent checks timeouts, non-owner release, and two non-cooperating
actions. The script uses the standard library only. Run it from the repository root:

```bash
PYTHONPATH=src python3 - <<'PY'
import os, subprocess, sys, tempfile, time, warnings
from pathlib import Path

# src/filelock/version.py is generated by hatch-vcs at build time and is absent from a bare checkout,
# so stub it in memory instead of building, installing, or writing into src/.
PRELUDE = """
import sys, types
from pathlib import Path
if not Path("src/filelock/version.py").exists():
    sys.modules["filelock.version"] = stub = types.ModuleType("filelock.version")
    stub.version = "0+unbuilt"
"""
exec(PRELUDE)
warnings.simplefilter("always")
import filelock
from filelock import FileLock, Timeout, UnixFileLock

HOLDER = PRELUDE + """
import os
from filelock import FileLock
lock = FileLock(sys.argv[1])
lock.acquire()
print("held", os.getpid(), type(lock).__name__, flush=True)
sys.stdin.readline()
lock.release()
print("released", flush=True)
"""

results = []
def check(name, ok, detail=""):
    results.append(ok)
    print(f"{'PASS' if ok else 'FAIL'}  {name}" + (f"  [{detail}]" if detail else ""))

def try_acquire(path, **kw):
    lock, t0 = FileLock(path), time.perf_counter()
    try:
        lock.acquire(**kw)
    except Timeout:
        return None, time.perf_counter() - t0
    return lock, time.perf_counter() - t0

print("python", sys.version.split()[0], "| filelock", filelock.__version__, "from", Path(filelock.__file__).parent)
print("has_fcntl", filelock.has_fcntl, "| FileLock is", FileLock.__name__)

with warnings.catch_warnings(record=True) as caught, tempfile.TemporaryDirectory() as tmp:
    lock_path, data_path = os.path.join(tmp, "data.lock"), Path(tmp, "data.txt")
    with subprocess.Popen([sys.executable, "-c", HOLDER, lock_path], stdin=subprocess.PIPE,
                          stdout=subprocess.PIPE, text=True) as holder:
        try:
            line = holder.stdout.readline().split()
            check("ownership: child process holds a native flock",
                  line[:1] == ["held"] and line[2:] == ["UnixFileLock"], " ".join(line))

            lock, elapsed = try_acquire(lock_path, timeout=0.5)
            check("timeout: contender raises Timeout after the timeout", lock is None and 0.5 <= elapsed < 1.5,
                  f"{elapsed:.3f}s for timeout=0.5")

            lock, elapsed = try_acquire(lock_path, blocking=False)
            check("timeout: blocking=False raises Timeout at once", lock is None and elapsed < 0.2, f"{elapsed:.3f}s")

            other = FileLock(lock_path)
            other.release()
            other.release(force=True)
            lock, _ = try_acquire(lock_path, blocking=False)
            check("ownership: non-owner release()/release(force=True) is a no-op",
                  lock is None and not other.is_locked, "child still holds")

            data_path.write_text("written by a process that never asked for the lock")
            check("advisory: non-cooperating writer modifies protected data while held",
                  data_path.read_text().startswith("written by"), "write succeeded")

            os.unlink(lock_path)
            intruder, elapsed = try_acquire(lock_path, timeout=0.5)
            overlap = intruder is not None and intruder.is_locked and holder.poll() is None
            check("advisory: after a non-cooperating unlink a new FileLock acquires while the child still holds",
                  overlap, "two simultaneous holders (old vs new inode)")
            if intruder is not None:
                intruder.release()

            holder.stdin.write("\n")
            holder.stdin.flush()
            check("ownership: holder releases its own lock", holder.stdout.readline().strip() == "released")
            holder.wait(timeout=5)

            lock, elapsed = try_acquire(lock_path, timeout=2)
            lock.acquire()
            reentrant = lock.lock_counter == 2
            lock.release()
            still_held = lock.is_locked and lock.lock_counter == 1
            lock.release()
            check("ownership: free lock acquires; same-instance reentrancy counts 2 -> 1 -> 0",
                  reentrant and still_held and not lock.is_locked and type(lock) is UnixFileLock, f"{elapsed:.3f}s")
            check("unix backend leaves the lock file in place after release", os.path.exists(lock_path))
        finally:
            if holder.poll() is None:
                holder.kill()
    fallback = [w for w in caught if "SoftFileLock" in str(w.message)]
    check("no silent fallback to SoftFileLock", not fallback, f"{len(caught)} warning(s) recorded")

print(f"RESULT: {sum(results)}/{len(results)} checks passed")
sys.exit(0 if all(results) else 1)
PY
```

## Limitations

- **Unbuilt package.** A bare `PYTHONPATH=src python3 -c "import filelock"` fails with
  `ModuleNotFoundError: No module named 'filelock.version'`. That file is generated at build time
  (`pyproject.toml:106-107`, gitignored), so the check stubs it in memory and `__version__` reads `0+unbuilt`. The
  built wheel and its packaging were not exercised.
- **Repository test suite not run.** No project venv exists, and installing the dev dependencies was out of scope.
  The pre-installed `pytest` 9.1.1 (a uv tool) lacks the plugins the config needs. First failure:
  `PytestConfigWarning: Unknown config option: asyncio_default_fixture_loop_scope`, promoted to an error by
  `filterwarnings = error`. With that warning ignored, collection fails at `tests/test_filelock.py:189` with
  `PytestUnknownMarkWarning: Unknown pytest.mark.timeout`. The tests cited above were read, not executed.
- **Narrow platform coverage.** One Linux host, one local ext-family filesystem, one UID (root), so permission and
  sticky-bit paths were not exercised. Not covered: Windows (`msvcrt`), NFS/CIFS/FUSE, the `ENOSYS` soft fallback,
  `SoftFileLock`/`StrictSoftFileLock`/`SoftFileLease`, read-write and async locks, `thread_local=False`, `fork`
  inheritance, and cross-host coordination.
- **Inferred, not observed.** The overlap check treats the child as still holding the lock because the child is alive
  and blocked before its `release()` call. It does not query the kernel (for example `/proc/locks`).
- **Loose timing bounds.** The timeout bound (0.5 s to 1.5 s) is deliberately loose for a shared container. It does
  not measure poll-interval precision or behavior under load.
